# Портфельный Информер v4 — сервер и PWA

Реализация релиза **R1** по ТЗ «Портфельный Информер» v4.0, плюс часть R2: все 7 таймфреймов, алерты INDICATOR и SIGNAL_CHANGE.
Сервер работает на домашнем ПК под Windows. Телефон и компьютер открывают веб-приложение через туннель, уведомления приходят в Telegram.

```
провайдеры (MOEX ISS, Finnhub, Twelve Data) → коллектор (раз в 300 с) → SQLite (свечи, котировки)
  → сервис индикаторов → кэш (indicator_cache) → API / движок алертов → PWA и Telegram-бот
```

Отличие от рекомендуемого стека (10.2): клиент написан на чистом JavaScript без сборки, а не на React + Vite. Его не нужно собирать, и сервер раздаёт его как есть. pandas не используется, индикаторы считаются на numpy.

**Не проверено на живых данных.** Пути и поля MOEX ISS, Finnhub и Twelve Data написаны по документации. Сеть к ним из среды разработки была закрыта, поэтому проверены только формулы и API на синтетических данных (`tests/`). При первом запуске загляните на вкладку «Состояние»: ошибки разбора ответов будут видны там и в `informer.log`.

## Установка на Windows

1. Установите Python 3.12 с python.org и при установке отметьте «Add python.exe to PATH».
2. Скачайте репозиторий: на GitHub нажмите **Code → Download ZIP** и распакуйте, например, в `C:\Informer`.
3. Откройте папку `server` и дважды щёлкните `start.bat`. При первом запуске он создаст окружение, поставит зависимости и откроет `.env` в Блокноте.
4. Заполните `.env`:
   - `APP_TOKEN` — длинная случайная строка, это пароль от веб-интерфейса;
   - `FINNHUB_KEY` — бесплатный ключ с finnhub.io (котировки США);
   - `TWELVEDATA_KEY` — бесплатный ключ с twelvedata.com (свечи США);
   - `TELEGRAM_TOKEN` — создайте бота у @BotFather, команда `/newbot`;
   - `TELEGRAM_CHAT_ID` — напишите своему боту любое сообщение, затем откройте `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и возьмите `message.chat.id`;
   - `BACKUP_DIR` — папка для копий БД, лучше в OneDrive или на другом диске.
5. Снова запустите `start.bat` и откройте в браузере http://127.0.0.1:8800. Введите токен.
6. Автозапуск: правой кнопкой мыши на `install_autostart.bat` → **Запуск от имени администратора**. Сервер будет стартовать при входе в Windows и перезапускаться при сбое.

## Если не запускается

Окно `start.bat` показывает журнал сервера; он же пишется в `server\informer.log`. Когда всё в порядке, в окне видна строка «Сервер запускается: http://127.0.0.1:8800» и сам открывается браузер. Окно не закрывайте: закрытие останавливает сервер.

Запустите `diagnose.bat`: он проверит Python, зависимости, `.env`, импорт приложения, порт 8800, доступ к MOEX, Finnhub, Twelve Data и Telegram, а также покажет хвост журнала.

## Доступ с телефона (туннель)

Порты роутера не открываем. Нужен один из вариантов:

- **Tailscale** (проще): поставьте Tailscale на ПК и iPhone под одним аккаунтом. На ПК выполните `tailscale serve --bg 8800`, а на iPhone откройте адрес `https://<имя-ПК>.<tailnet>.ts.net`. Сервер слушает только 127.0.0.1, поэтому снаружи он доступен лишь через туннель.
- **Cloudflare Tunnel** (нужен свой домен в Cloudflare): `cloudflared tunnel login`, затем `cloudflared tunnel create informer` и `cloudflared tunnel route dns informer informer.ваш-домен.ru`. В конфиге укажите `service: http://localhost:8800` и установите службу командой `cloudflared service install`. Адрес туннеля впишите в `PUBLIC_URL`.

На iPhone откройте адрес в Safari и нажмите «Поделиться» → «На экран Домой».

**Сторож:** заведите бесплатный монитор (например, UptimeRobot) на `https://<адрес>/healthz` с уведомлением в Telegram. Он сообщит, если ПК выключен.

## Команды бота

`/portfolio`, `/pos`, `/ta SBER 1d`, `/alerts`, `/alerts off 3`, `/mute 3`, `/mute`. Команды `/calendar` и `/news` появятся в R2.

## Разработка

```bash
pip install -r requirements.txt
python -m pytest -q          # формулы разделов 3, 4, 6, 7 и сквозной тест API
python -m tests.demo         # демо на синтетических данных: http://127.0.0.1:8800, токен demo
```

Состав Nasdaq-100 (`app/data/nasdaq100.json`) и праздничные дни бирж (`app/data/holidays.json`) обновляются вручную.
